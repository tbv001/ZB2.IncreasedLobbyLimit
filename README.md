# Increased Lobby Limit

**Increased Lobby Limit** is a mod for **Zumbi Blocks 2** that quadruples the maximum player count of a lobby.

## Features

- Increases player limit from 6 to 24
- Updates the lobby interface to accommodate the increased player limit (doesn't include the player list UI at the moment)

## Installation

1. Make sure you have the latest version of **BepInEx 5** installed
2. Download the latest version of the mod from the [releases](https://github.com/tbv001/ZB2.IncreasedLobbyLimit/releases) page
3. Copy the DLL file into the `plugins` folder of your BepInEx installation:

```
Zumbi Blocks 2 Open Alpha\BepInEx\plugins\IncreasedLobbyLimit.dll
```
